# 17 · 明确文件监听生命周期

类型：条件性检查。状态：待办。依赖：无。遵守[任务索引](README.md)的全局约束。

**对象**：`Workspace` 的 watcher task、stop token、启动/停止函数。见 [workspace/mod.rs](../../crates/yourai-core/src/workspace/mod.rs)。

**原因**：取消 token 不能复用，现有接口是否承诺重启不明确；当前调用可能只需要单次生命周期。

**怎么改**：核查真实调用；单次生命周期则说明/收窄接口，只有合法重启需求才处理旧 handle 和新 token。

**验收**：给出明确结论；若支持重启，验证启动、停止、再次启动及关闭后不再发事件。

**保持**：没有重启需求时不新增状态机，不删除现有关闭清理。
